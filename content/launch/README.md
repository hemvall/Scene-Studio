# Épisode 01 · Lew a supprimé les réunions

Préparé pour le 16 octobre 2026. Sketch fictif, 23 secondes, français, vertical 1080 × 1920. Ne pas présenter la suppression des réunions comme une fonctionnalité réelle de Lew.

## Ouvrir dans Scene Studio

Ajouter `#example=launch-meeting` à l’URL du studio. Ce lien crée un projet indépendant, même si une bibliothèque existe déjà. Ou New reel → Examples → « 01 · Lew a supprimé les réunions ».

Aucune intro. Le patron joue la scène sincèrement ; Lew parle sans sourire ni appuyer la blague. Les sous-titres sont incrustés par le moteur. Les durées sont des cibles avant génération des voix ; le moteur recale les plans sur les clips.

## Finaliser aujourd’hui

1. Script → Voice : sélectionner deux voix françaises distinctes avec le fournisseur déjà configuré dans le navigateur. Lew : posé, jeune adulte, neutre, légèrement las. Patron : assuré, débit naturel, progressivement contrarié. Aucun accent britannique pour cette version.
2. Générer les voix. Écouter la prononciation de « Lew » et les silences après « Exactement » et « Toi ». Si nécessaire, ajuster le rythme dans le script puis les plans.
3. Vérifier le cadrage portrait, les sous-titres et les niveaux au casque. Pas de musique forte sur les silences comiques.
4. Export → MP4, Reel 1080 × 1920. Regarder le fichier exporté en entier sur téléphone avant publication. Le projet reste draft tant que cette vérification n’est pas faite.

Les clés et les voix du navigateur ne sont pas accessibles dans le dépôt. Aucun MP4 avec voix n’est fourni par ce changement.

## Publication

Couverture : **IL A SUPPRIMÉ LES RÉUNIONS**. Prendre une image du patron au début ; conserver le visage et le titre dans la zone centrale pour les recadrages du profil.

Légende :

> On lui a demandé de nous faire gagner du temps.
> Il a commencé par le calendrier.
>
> Qui reconnaît son lundi matin ?
>
> #Lew #VieDeBureau #IA

Le sketch ouvre le compte sur un problème de bureau reconnaissable et installe la personnalité de Lew. Le nombre de vues ne peut pas être garanti. Après publication, observer les abandons dans les premières secondes et les partages pour choisir le prochain épisode.
